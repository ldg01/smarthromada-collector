# smarthromada-collector

Збирач дописів стрічки для «Кабінету мешканця / Smart Hromada».

Запускається GitHub Actions за розкладом (`.github/workflows/collect.yml`):
боти збирають погоду, повітря, рівень води, тривоги, відключення, календар
подій, новини громад тощо й надсилають готові дописи на сервер сайту.

`collector.mjs` — зібраний файл; вихідний код — у приватному репозиторії сайту.
Ключ доступу до сервера зберігається лише в секретах репозиторію.
